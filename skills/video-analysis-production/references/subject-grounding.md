# 人物与商品主体识别及建档规范

## 1. 主体分类（`kind`）

`characters` 数组不仅记录角色，也记录一键复刻中需要替换或保持一致的核心商品/关键道具：

- `kind: "person"`：**真实出镜人物**（包含主角、配角、交互路人）。
- `kind: "product"`：**需要跨镜保持外观一致的核心带货商品、关键道具或固定吉祥物**（如“棕色牛皮信封”“磨砂玻璃精华液瓶”“银色无线降噪耳机”）。若商品只是一般环境陈设且不作为主体，不必单独建档；若原片核心围绕商品展示或交互（如开箱、递送核心道具、电商口播带货），**应当**建立 `kind: "product"` 主体。

## 2. 跨镜唯一 ID 原则

- **同一主体跨镜唯一 ID**：例如女主在第 1 镜近景、第 2 镜背影、第 4 镜换景出现，全程只能用同一 ID（如 `role_1`），不得新建 `role_4`。
- **区分多人与人群**：有明确戏份或正面互动的人物分别建 `role_1`、`role_2`...；无关虚化背景行人归入 `scene` 环境描述，不必污染人物清单。
- **旁白隔离原则**：只在画外发声、全片从未出镜的旁白解说员，**禁止**写入 `characters`；可在相应镜头的 `speaker` 中填写 `"旁白"`。
- **上限约束**：最多 `30` 个主体，`id` 仅允许字母/数字/下划线/连字符（推荐 `role_1`、`role_2`、`prod_1`），不得使用保留字。

## 3. `appearance` 外貌与商品锚点写法

`appearance` 用于跨镜生图参考与人物/商品一致性对齐，必须用简洁密集的**客观视觉特征**写成，不要写性格评价或剧情心理：

- **人物（`person`）必填 5 要素**：大致年龄段与性别特征 + 发型发色（含长度/束发细节） + 面部显著特征（眼镜/胡茬/妆容色系） + 核心服装层叠与颜色（外衣+内搭） + 标志随身物。
  - 优良示例：`26岁左右东亚女性，黑色及肩直发微湿垂落额前，素雅淡妆，身穿卡其色双排扣风衣内搭深棕高领针织衫。`
- **商品/核心道具（`product`）必填 4 要素**：品类形态 + 材质反光特性 + 主体配色与标签文字区（不臆造虚假品牌词） + 典型尺寸/握持尺度。
  - 优良示例：`15厘米高柱状琥珀色磨砂玻璃滴管精华瓶，搭配哑光黑色胶头与金色铝制中环，瓶身正面带极简白色排版标签。`

## 4. 每镜 `shot.characters` 标注纪律

- 仅填写**该镜头画面里真实可见**的主体 ID（含局部手部出镜递物但明确属主的情况）。
- 空镜、纯文字黑屏、无人且无建档商品的环境空镜，`shot.characters` 必须为空数组 `[]`。
- 禁止在同一镜头的 `characters` 数组中重复同一个 ID。
