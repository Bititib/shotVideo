# 镜头切分与节奏结构规范

## 1. 真实切镜识别原则

- **以画面不连续为准**：硬切（Cut）、叠化（Dissolve）、白帧/闪黑转场、明显机位跳变（正反打、全景切特写、A-Roll 切 B-Roll）均视为新镜头起点。
- **不将单镜内部运镜误判为切镜**：同一连续镜头内的推拉摇移或人物走位保持为单个分镜，通过 `camera` 与 `videoPrompt` 表达运动过程。
- **短促插切处理**：极短反应镜、商品微距空镜或节奏卡点镜（≥ 0.4s）若承载独立构图与主体变化应保留；< 0.3s 的纯闪光/转场残影并入前后主镜。

## 2. 连续时间轴校验数学（对接 `validatePlan`）

生成分镜时间轴时必须满足以下硬约束：

- 首镜起点：`|shots[0].start - 0| <= 0.15`（建议精确设为 `0`）。
- 逐镜递增：每镜 `start >= 0` 且 `end > start`，单镜时长建议保留一位或两位小数。
- 相邻无缝衔接：对于任意 `i >= 1`，`|shots[i].start - shots[i - 1].end| <= 0.15`（建议直接让 `shots[i].start === shots[i - 1].end`）。
- 全片收口：`|shots[shots.length - 1].end - duration| <= 0.2`，禁止截断片尾或超出 `duration + 0.15`。
- 规模上限：镜头总数 `1 <= shots.length <= 80`，分镜 `id` 使用两位数顺序字符串（如 `"01"`, `"02"`...）。

## 3. 叙事与带货结构识别指南

在 `hook`、`continuity` 与各镜 `title` 中体现原片节奏职责：

- **开场钩子（0–3s）**：识别原片用什么抓人（悬念动作、冲突对白、痛点特写、强节奏卡点），清晰写入 `hook`。
- **中段推进**：在分镜标题中标注功能（如 `对话建置`、`成分演示`、`情绪反打`、`对比证言`、`悬念停顿`）。
- **收尾转化/留白**：末尾镜头需交代最终落点（产品全景定格、行动号召口播、背影离去或情绪悬念）。
- **统一度摘要（`continuity`）**：概括全片不变的视觉锚点——主色调/色温（如“暖橙室内灯 + 冷青雨夜霓虹”）、年代/时代服饰风格、核心场景与光照方向，供下游全片生图参考。
