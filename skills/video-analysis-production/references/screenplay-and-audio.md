# 纯文本剧本字段与听觉分层规范

为兼顾视频专业复刻的“纯文本剧本阅读体验”与“多轨生成对齐”，每个分镜需将视觉与听觉拆分为正交字段，**严禁把镜头运镜、生图提示词、AI腔形容词混进纯文本剧本体**。

## 1. 五个纯文本剧本/听觉字段定义

| 字段 | 职责定位 | 写作标准与示例 |
| --- | --- | --- |
| `scene` | 时间、地点与光照氛围（类传统剧本场号头） | 紧凑短语，格式为 `昼/夜 · 空间地点 · 光影/气象`，如 `雨夜 · 老旧公寓木门外 · 门廊暖灯与湿润石阶`；上限 200 字内为佳 |
| `action` | 该镜内人眼可见的核心动作与节奏变化（纯舞台提示，不写机位命令） | 用白描动词写出“谁在做什么、结果是什么”，如 `陈默从口袋抽出潮湿的牛皮信封递向前方，阿宁双手接过并低头停顿。` |
| `speaker` | 声音归属标签 | 出镜人物说话写其 `name`（如 `陈默` 或 `阿宁`）；画外解说写 `旁白`；多人对谈写主讲人或 `陈默/阿宁`；纯默片/无口播镜头写 `无对白`（或留空字符串 `""`） |
| `caption` | 精确口播与画面对话字幕（逐字还原） | 原片人物开口或旁白朗诵的真实台词文本；严禁把镜头说明或环境噪音写入 `caption`；无对白无字幕时填 `""` |
| `audio` | 非语言听觉线索（环境音、拟音 SFX、BGM 情绪变化） | 提炼声场氛围与卡点声音，如 `细密雨声与木门轻叩两下、低沉大提琴单音`；若完全静音填 `静音` 或 `""` |

## 2. 纯文本区分度约束

- **`action` vs `videoPrompt` 区分**：
  - `action` 面向导演与编剧阅读，只写戏剧行为与物理事件（例：“她将精华液滴在手背并推开，露出水光反光”），**不写**“镜头缓慢推近”“8K摄影质感”。
  - `videoPrompt` 面向图生视频引擎，融合动作时序 + `camera` 运镜轨迹 + 光影变化。
- **`caption` vs `audio` 区分**：
  - 只要是人声说出的话或屏幕硬字幕烧录的口播文字，落入 `caption`（并与 `speaker` 对应）。
  - 只要是脚步声、快递盒拆封声、风声、转场 whoosh 音效、背景配乐起伏，落入 `audio`。
- **原语言忠实**：`caption` 保持视频真实语音文字（中文原片输出中文；若有外语口播按原语种或双语简明记录，不篡改原意）。
