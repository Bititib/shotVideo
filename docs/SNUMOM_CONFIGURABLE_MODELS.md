# snumom 同接口后台配置

基线：origin/main `6764359`。工作区：`scratch/snumom-configurable`。已完成本地实现和模拟验证；用户授权提交 GitHub，明确要求不部署、不备份、不修改现有价格和历史余额。未调用付费生成。

## 协议与范围

2026-11-19 只读核对 https://snumom.com/docs/wan-3.0.html：Bearer 鉴权，JSON `POST /v1/videos`，字符串 `seconds`，`size`、`aspect_ratio`，`reference_images` 带角色，`reference_videos`/`reference_audios` 对象数组；原 `id/task_id` 查询 `GET /v1/videos/{task_id}`。保留 snumom 专属响应解析、拒绝规则和脱敏。

后台渠道 → 模型与参数 → 添加新模型：读取当前 Key 的 `/v1/models` 授权目录，选原始 ID，填写显示名称、固定/枚举/范围时长、默认秒数、分辨率、画幅、各类素材数量、合计上限、首尾帧，以及按次/按秒、参考视频是否计费。

只支持已确认使用相同 JSON 契约的型号；不是任意模型自动适配。Token 计费、聊天生成、任意字段模板、智能时长、文档/网页参考和额外参数未开放。不得把仅出现在授权目录当作具体参数已被上游确认：管理员须按该型号文档配置限制。

已有内置型号继续走原有接入配置，不迁移、不开放覆盖其特殊规则。后台新加的型号可再次编辑；新型号默认停用，不创建/改写售价，配置售价后再启用。计费方式与实际售价单位不符时在扣费前拒绝；价格金额仍在“关联型号与价格”设置。

## 执行链路

- 后台现有 `model-configurations` 管理 API → `channelModelConfigurationService` 保存单一规格和带 `snumom` 策略的路线。带版本检查的事务保存；授权目录查询期间配置变化则拒绝。渠道同步、启动清理通过 `channelCatalogBindings` 保留有效自定义路线。
- 网站 `/api/video/generate` 和 API `/v1/videos` → `handleSpecificationGeneration`。参数标准化、数量/时长/组合校验、选择原渠道、探测参考时长、核对售价单位、报价后才创建订单和预扣。
- 批量 `/api/video-batches` → 网站 `/validate` 得到相同费用 → 批量账本 → 原网站规格生成入口。执行时费用不符拒绝新提交；不再扣一份生成费用。不同创意费用不同须分批，沿用现有批量限制。
- 参考计费：每段服务器探测后向上保留 0.1 秒，加总计费；客户端 duration/reference_video_seconds 不作为扣款依据。探测失败不下单、不扣费。音频不计费。按次不会乘视频秒数。
- 报价页面和画布传递参考视频至只读报价接口；服务端探测只对配置为参考计费的新型号执行。
- 新订单保存计费策略、探测结果和售价快照；后台后续改价/改策略不影响已预扣订单。此通用契约按提交的输出秒数及探测参考秒数结算，不借用其他型号的实际用量/Token 规则。
- `submitSpecificationVideo` → 原提交占用/账本 → snumom JSON 提交 → 原任务 ID 持久化、即时终态或查询 → 幂等结算。即使非 2xx 携带有效 snumom 任务 ID 也保留并查询原任务，不用 HTTP 状态提前退款。响应缺 ID、断链、非 JSON 继续原待核实保护，不重放 POST。
- 恢复沿用 `resumeSpecificationTasks` 原渠道/原 ID；查询异常不当生成失败。旧渠道与旧资金路径无迁移。

## 验证

新增实际 HTTP 入口和隔离 SQLite 账本测试：网站/API 成功、失败、明确无渠道、超时、非 JSON、缺 ID、即时成功/失败、参考计费/免费、探测失败、错误价格单位、参数超限；相同 API 幂等键并发且无限 Token 退款一次；真实批量桥接执行及重复批次；非 2xx 有 ID、查询临时失败后成功；中途修改策略/售价仍按原快照结算；后台表单保存及同步保留配置、无价格/余额改写。

最终相关 12 个测试文件 504 项通过，另画布 108 项通过，合计 612 项。类型检查和生产构建通过；构建保留现有包体积/混合导入警告。扩大范围的 `modelCatalog` FunAI 元数据断言与 `videoCapabilities` 测试缺 route.id 两项失败，在未修改基线 `6764359` 完整复现，未混入无关修复。

未做真实上游付费测试，不能以模拟验证保证上游每个新型号的参数都相同；新增时必须按型号能力填写。未读取或修改生产价格、历史任务、用户余额。

## 标准版和高速版重新接入

旧下架规则只对渠道 14 的显式同名配置放行：`wan3.0-video`、`wan3.0-video-prime` 须由管理员从授权目录保存，不随同步自动接入或启用。可复用停用的旧 snumom 型号记录；不重置售价。旧绑定、通配或跨渠道映射仍不放行；重启清理只保留符合条件的新规格。

按公开文档限制整数 2–30 秒、最多 10 图/5 视频/5 音频，输出加参考视频合计不超过 30 秒。不开放智能时长。本站按提交的输出秒数加服务器探测并逐段向上保留 0.1 秒的参考视频结算，音频不收费；不依据上游实扣账单二次调整本站任务。
