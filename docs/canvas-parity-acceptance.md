# 画布对标验收清单

当前状态：基础画布与部分生成节点已实现，不能视为达到 Updream / NeoWOW 的完整产品标准。按钮存在、模拟接口测试通过与真实创作流程通过应分别记录。

## 完整流程标准

| 流程 | 当前缺口 | 完成时必须可以实际验证 |
| --- | --- | --- |
| 参考素材接入 | 已识别视频/音频连线；本轮接入单视频编辑，其他多模态模式尚未接入 | 连接后显示素材类型、用途和数量；不支持的组合提前说明；实际请求包含被选素材 |
| 视频编辑 | 已接入 Veo 视频编辑模式、原片关联、参数与时长检查；真实生成仍待联调 | 视频节点连接编辑节点，填写修改要求，生成新视频，保留原片与参数；时长、比例、参考数量与后端一致 |
| 图片局部修改 | 目前只有整图参考、中心裁剪、旋转；图像路由未接收蒙版 | 在图片上选择区域、撤销选区、修改选区内内容；后端支持并验证蒙版，输出保持画幅和版本历史 |
| 节点连续执行 | 连线只提供单节点上下文，没有工作流调度 | 展示执行顺序、费用确认与依赖；上游成功后传递结果，失败时下游停止；断线重开不重复计费 |
| 多结果继续创作 | 可在历史窗口恢复/复制，但结果选择与后继引用关系不清楚 | 在节点直接选择结果；下游明确引用哪一版，改选后标识需要重新生成，旧成品不被覆盖 |
| 创作面板 | 浮层仍有遮挡、参数需滚动，节点缺少稳定的类型和输入角色表达 | 常用提示词、参考素材、模型参数和生成入口可快速操作；平移、缩放、框选不会误改输入 |
| 视频成片 | 无时间线、多镜头排序、配音对齐和合成导出 | 多段素材排序、预览、设置时长和音轨，导出实际可播放的成片 |
| 项目与资产 | 快照保存、内嵌媒体；预览尚未联通真实生成后端 | 登录后的真实项目保存、跨设备恢复、素材失效提示、任务恢复与权限隔离通过端到端验收 |

## 本次代码核对证据

- 原始缺口：画布仅识别文字及图片引用。本轮已扩展至媒体引用，并提前拒绝当前模式不支持的类型。
- 原始缺口：画布排除了视频编辑模型。本轮已在独立编辑模式允许现有 Veo 编辑模型，普通视频模式仍不会混入编辑模型。
- `server/routes/video.ts` 已处理 `reference_videos`、`audio_urls`、首尾帧，并对 Veo 编辑的单参考视频、禁止音频参考、画幅与时长进行校验。
- `server/routes/imageGen.ts` 的生成参数包含多参考图，不包含局部修改蒙版。局部重绘不能仅加一个画笔按钮就宣称完成。
- `client/src/canvas/model.ts` 只有媒体种类，没有工作流执行状态、输入角色、版本引用和依赖失效定义。

## 交付门槛

1. 选定主线要从导入参考到导出作品走通，不能以新增入口数量验收。
2. 对每个模式记录已接通的模型、输入限制、费用规则、失败与恢复行为。
3. 独立测试覆盖依赖、参数与计费去重，浏览器验证实际操作；真实生成另做明确记录，不能用模拟结果替代。
4. 未接通的能力明确列为未实现，不放置暗示已可用的入口。
5. Agent、导演台、3D World 和多人协作分别规划，不混入本轮基础创作流程完成率。

## 视频编辑第一段交付（2026-09-30）

- 原视频节点新增“编辑视频 · 保留原片”，建立关联编辑草稿；原片与新节点独立保存。
- 编辑模式仅展示后端已有的 Veo Omni Flash 视频编辑模型，限定一个原视频、禁止音频参考、16:9/9:16、10 秒输出；允许附加图片。模式切换不静默丢弃不支持的媒体，显示原因并阻止提交。
- 提交前读取原视频元数据，超过 15 秒、读取失败或超时均停止，不发送生成请求；取消时清理媒体读取。
- 提交参数带 reference_videos、参考图、画幅和时长，沿用已有请求编号去重、任务恢复、节点版本历史和结果回填。
- 本地三秒测试视频已导入独立验收项目，并创建关联编辑草稿。测试视频是本地测试图案，不是 AI 生成成品。
- 七组 52 项测试通过；后续界面微调重跑相关两组 26 项通过，类型检查与生产构建通过。原片保留、请求参数、结果回填、超时长不提交和草稿恢复有测试覆盖。
- 当前预览无后端连接，模型目录暂不可用，没有实际提交收费模型；真实生成和账户权限端到端验收仍未通过，不计为完整视频成片流程交付。视频延长、时间线合成和自动工作流仍待实现。

## 视频、音频参考上传（2026-09-30）

- 实际查看已登录的 Updream 与 NeoWOW 编辑器：Updream 的全能参考素材窗口按图片、视频、音频分类；NeoWOW 支持连接参考素材、提示词中使用 @ 引用，并提供分类素材库与画布资产。仅观察界面，没有上传到对标网站或提交收费生成。
- 本站创作面板新增直接上传与拖入参考文件，自动创建素材节点并连接当前创作节点；视频可预览、音频可试听，移除参考只断开连线，不删除素材。图片上限 20 MB，视频和音频上限 40 MB。
- 新增多模态参考模式，按已核实的后端能力筛选模型；支持的请求发送 reference_images、reference_videos、audio_urls。不同模型的数量限制、VD 不接受音频、Wan3.0th 仅接受 WAV 均在提交前检查，不静默忽略参考。
- 七组 56 项测试、类型检查与生产构建通过。浏览器真实文件选择器导入本地测试视频和 WAV，确认自动连线、视频预览与音频控件；切换 VD 模型后正确提示音频不受支持。没有提交收费生成，实际供应商接收与生成质量尚未验收。
- 当前仍缺 @ 素材别名绑定、跨项目分类素材库和专用媒体对象存储上传流程；不能把本轮视为已达到两个对标网站的全部素材管理能力。视频时长等供应商专属限制仍以对应后端和供应商校验为准。
