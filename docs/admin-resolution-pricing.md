# 自定义模型的分辨率价格

计费管理通过 `/api/admin/pricing` 的 `resolutionOptions` 读取
`model_specification_routes_v1` 中对应本站模型 ID 的 `limits.resolutions`。
已配置规格优先于内置型号默认规格；没有规格配置的旧型号继续使用原有规则。
停用模型也可先配置价格再启用，读取价格不会修改模型状态。

在模型的「管理价格」中，可分别设置每个分辨率的售价。单位随计费方式显示：
视频按秒为元/秒，视频按条为元/条。新增分辨率输入框默认为空，不自动填写价格；
留空沿用原兜底单价，明确填写 0 表示免费。已有分辨率价格和其他附加价格保留。

保存仍使用原有 `extraParams` 结构与计费接口，不新增订单、不调用上游。
前台报价、API 报价与批量任务沿用既有计费服务；已保存的订单价格快照不重新定价。
本次不修改提交、轮询、回执恢复、扣款或退款流程，不需要数据库迁移。

回归覆盖：自定义模型首次配置、未定价停用模型、大小写去重、零价格、按秒和按条保存、
空值兜底、前台报价与 API 价格一致、旧快照保留，以及旧 HM 型号历史价格兼容。
