# 上游错误处理审计（2026-10-24）

## 规则

上游明确返回的错误码和原因必须保留。提示应包含发生阶段，以及可取得的 HTTP 状态、请求编号或任务编号。不得仅用“生成失败”“请重试”覆盖原因。上游没有提供原因时明确说明信息缺失，不能推测原因。

共用工具只负责诊断字段提取与脱敏，不负责统一判断上游任务状态、重试、退款或计费。各适配器仍按各自协议处理这些行为。密钥、Cookie、签名链接、请求正文和素材不展示。

## 验证

- 新增多渠道错误码与消息保留、密钥脱敏、非 JSON 请求编号、嵌套网络原因测试。
- 回归覆盖提交不确定、查询异常、退款一次性、保留原任务、禁止自动重复付费提交、前端恢复和 HTTP 402 合约。
- 类型检查通过；生产构建通过。Windows 默认临时目录导致 esbuild 清理失败，改用工作区临时目录后构建成功。
- 全量测试有 13 项既存失败，已在未修改的 be46f81 版本单独复现：canvasStudio 3 项、canvasVideoInputs 3 项、channelBaseUrlPersistence 2 项、zonghengVideoGrouping 5 项，均涉及旧 ZH 模型配置或展示。本次未改变这些模型的配置。
- 使用模拟上游响应与测试数据库；未发送真实付费生成请求，未修改生产数据库或环境配置。

## 边界

HTTP 状态或请求编号仅在上游实际提供时展示。HTML 网关正文、非法 JSON 与未列入诊断字段的内容不原样输出，避免泄露请求或页面内容；这类响应展示失败阶段、响应类型和可取得的状态、编号。错误处理修复不能代替上游服务恢复或修正用户的实际素材。
