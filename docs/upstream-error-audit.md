# 上游错误处理审计（2026-10-24）

## 规则

上游明确返回的错误码和原因必须保留。提示应包含发生阶段，以及可取得的 HTTP 状态、请求编号或任务编号。不得仅用“生成失败”“请重试”覆盖原因。上游没有提供原因时明确说明信息缺失，不能推测原因。

共用工具只负责诊断字段提取与脱敏，不负责统一判断上游任务状态、重试、退款或计费。各适配器仍按各自协议处理这些行为。密钥、Cookie、签名链接、请求正文和素材不展示。

## 边界

HTTP 状态或请求编号仅在上游实际提供时展示。HTML 网关正文、非法 JSON 与未列入诊断字段的内容不原样输出，避免泄露请求或页面内容；这类响应展示失败阶段、响应类型和可取得的状态、编号。错误处理修复不能代替上游服务恢复或修正用户的实际素材。
