# HUSS BB Seedance 渠道

HUSS 的 `bb-seedance2.5-301010` 映射为本站已有的公开模型
`bb-2.5-301010`，现有用户 API 无需更换模型名。

后台添加渠道时选择 **HUSS（BB Seedance 视频生成）**，填写
`https://www.huss.top` 和 HUSS API Key，然后测试连接并同步模型。

此型号支持 10–30 秒、720p、16:9/9:16/1:1，以及最多 30 张图片、10 段视频、
10 段音频。服务端以 Bearer Key 调用 `/v1/models`、`/v1/videos` 与
`/v1/videos/{id}`；本地上传的参考素材会转为无账号信息的公网临时地址。

保留旧 BlobDraw 渠道用于查询历史任务；验证 HUSS 可用后，在模型规格中启用 HUSS
线路并停用旧 BlobDraw 线路，避免新任务继续流向旧供应商。

### 2026-10-25：生产 403 原因核实

用户提供的记录表明 #14453 已于北京时间 15:01:37 完成并结算；#14454 查询 HTTP 200、上游 completed，但下载 HTTP 403。本地对原签名地址做只读检查，HUSS 返回 307，Cache-Control 为 private, no-store，跳转到 TOS。TOS 明确返回 Code=AccessDenied、Message=Request has expired。一次样本 ExpiresSeconds=60、Expires=2026-10-25T07:03:58Z、ServerTime=2026-10-25T07:04:03Z。请求 no-cache 后仍然复现。该证据指向上游短期签名时间/有效期问题；时钟偏差或中间延迟仍需 HUSS 排查，平台不能修改签名绕过过期校验。

补丁独立解析 HUSS/TOS 下载错误的 Code、Message、RequestId 及过期时间，避免被通用展示漏掉；原任务成功保存并结算后清空 resultSaveError。保留原任务重查与保存重试，不重新生成、不据下载失败退款。12 项相关测试、类型检查及构建通过。未宣称 #14454 已恢复，未保存或发布真实签名链接。
