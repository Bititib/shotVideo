# 无限画布改版说明

## 参考与边界

本次参考用户指定的 [Updream](https://www.updream.cn/) 和 [NeoDomain / NeoWOW](https://neodomain.cn/)。2026-09-29 访问时，后者跳转到 `/neo-tv`。

- Updream 的公开首页按剧本、角色、分镜组织创作入口，并展示可复用技能；新建画布进入登录页。
- NeoWOW 的公开页面将画布、图像、视频和作品创作过程串联，并提供画布项目管理入口。
- 未登录访问不能完整验证其编辑器，不宣称已复刻其内部功能。当前改版借鉴任务入口和素材关联方式，采用独立设计与实现。

## 已实现

- 独立全屏创作空间，保留首页与工作台入口。深浅主题、节点旁创作面板与底部常用工具；默认收起面板，选中创作节点展开。
- 图片、视频、文字节点；文件拖入、选择导入与剪贴板粘贴；素材命名、预览、下载。
- 平移、指针中心缩放、触控双指缩放、框选与 Shift 多选、集体拖动、调整卡片大小。
- 连接素材、阻止循环连接、断开连线、组合与取消组合、自动排列、复制、删除、撤销重做。
- 连接点支持按住拖拽，实时曲线预览、24 屏幕像素目标吸附、可连接/不可连接提示；支持从输入端反向拖动。空白松手弹出添加并连接节点菜单；Esc、指针取消或窗口失焦会取消拖拽，成功连线只占一个撤销步骤，逐点点击与键盘点击仍可用。浏览器已实际拖拽验证。
- 素材搜索、列表定位、缩略图导航、一键适应视图。恢复时自动找回全部落在视野外的素材。
- 分镜、产品视觉与情绪板三个可编辑模板；模板是结构起点，不会自动调用付费生成。
- 图像与视频生成面板复用本站模型目录、账户和接口，支持图片参考与已连接的文字上下文；生成结果留在画布上。
- 任务流式进度、结果回填、已有内容 ID 的任务轮询恢复；不确定是否提交成功时提示先核实生成记录，不自动重发计费请求。
- 多画布创建、切换、重命名、自动保存、备份导入导出；保留旧版 IndexedDB 原始记录并读取迁移。
- 自动保存合并高频编辑，串行写入防止旧版本覆盖新版本。离开页面时保存，未完成保存时提供浏览器离开提醒。

## 使用范围

访客项目保存在当前浏览器；登录后先存本地，再通过 `/api/canvas/workspace` 同步到当前账户。断网继续编辑，联网或点击保存状态重试。服务端按账户隔离，用修订号拒绝过时覆盖；出现冲突后刷新，会把未同步的本地版本另存为项目，保留两份作品。项目菜单可主动导入此浏览器的访客作品，不会自动归入其他账户。

当前云端以整个工作空间快照保存，限制为 100 个项目、每项目 1000 个素材、总计 80 MB；内嵌素材也计入空间。超限时保留本地副本并显示错误，仍可导出备份。尚未实现独立对象存储、大容量媒体库和多人实时协作。生成结果沿用本站后端内容记录。视频工作台的全部特殊模型参数仍可在完整工作台设置。备份中的外部素材依赖源地址有效，本地导入的素材数据包含在备份中。

## 创作流程与任务恢复（第二阶段）

- 图片选中后可“继续修改”或“生成视频”：创建关联草稿并自动引用图片，原图保留，点击生成才提交。
- 两张图片多选后可并排对比，查看提示词、模型与参数，并选择一个版本继续创作。当前是节点版本对比，尚非自动版本树。
- 素材列表支持搜索其他项目并复制素材，保留来源信息，不带入旧任务身份。
- 创作面板的提示词、模型、比例、分辨率和时长按节点保存为草稿；收起、切换和刷新后仍可继续。已生成素材的原始参数另行保留。
- 每个生成请求带唯一任务编号，提交前落本地；后端 `canvas_requests` 持久记录编号和内容记录 ID。重复请求仅返回原任务，不再次进入计费或生成逻辑；同编号不同参数拒绝。
- 即使流式响应丢失内容 ID，也可以通过 `/api/canvas/requests/:id` 恢复；收到 ID 后沿用内容记录轮询回填结果。未知提交状态不自动重发，提示核实生成记录。服务进程在拿到上游任务标识前崩溃的情况仍需人工核实。
- 视频按次或按秒计费的模型显示估算价格；按 token 等无法准确预估的模型保留实际计费说明。
- 服务端新增表在首次画布请求时建立；已有生成入口不带画布任务编号时沿用原行为。

本地 4179 为前端构建预览，当前没有连接生成后端。接口与生成结果处理采用模拟响应验证，未实际调用收费模型。

## 登录态对标与节点创作改造（2026-09-29）

本轮直接检查用户已打开的 Updream 和 NeoWOW 编辑器，而非仅依据官网介绍。未提交生成请求或修改对标项目内容。

- Updream 实际编辑器：生成节点、节点旁提示词/模型/比例/数量面板、底部画布导航、节点类型菜单（Agent、图像、视频、音频、文本、预演台）。
- NeoWOW 实际编辑器：节点生成历史，视频面板的文生视频、全能参考、视频编辑、视频延长、动作模仿、运镜入口，以及 Tab 添加节点菜单中的图层编辑、视频合成、导演台、3D World 和批量导入入口。上述是观察到的入口，未验证其收费生成效果。

### 本轮交付

- 节点旁编辑器：优先放在节点下方，空间不足则放在左右侧；底部工具栏保持可见；窄屏以底部浮层展示。深色默认，支持切换浅色。
- 图像单次 1/2/4 张；全部结果保留在节点历史中，可恢复或复制到画布。再次生成复用生成节点并保留旧图，普通导入图仍作为独立参考保留。
- 节点历史存储最近 100 个结果；批次中的单张结果不会提前把多图任务标为完成；终态重复 URL 去重。关联文字作为上下文提交，不反复追加到草稿。
- 视频区分文生视频、图片参考、首尾帧。首尾帧只允许当前识别的 Veo / Wan 3.0 模型并校验有效素材；后端仍按实际通道能力校验。运镜按钮只插入明确的提示词，不声称具备专用镜头引擎。
- 音频节点接入已有 TTS 模型与配音接口，支持音色、播放、下载、历史保留及备份恢复。音频未接入图像/视频的请求编号恢复机制，响应不明时提示到生成记录核实，不自动重发。
- 生成资产抽屉调用当前账户已有内容接口，搜索、图片/视频筛选、分页、多图结果加入画布；访客需登录。
- 图片居中裁剪、90 度旋转、水平翻转，使用浏览器真实处理并创建新节点，保留原图。最大处理边长 4096；不等同于涂抹重绘或图层编辑器。
- 每行一条提示词批量创建 1–20 个独立图片/视频草稿；创建过程不调用模型，不是批量自动生成队列。
- 连线显示开关、24 单位拖动吸附、连接下一步的一次撤销。

### 仍未对齐的能力

Agent 自动编排、通用文本生成、涂抹重绘和图层编辑、视频编辑/延长/动作模仿/全能多模态参考、时间线视频合成、导演台、3D World、多人实时协作和独立对象存储尚未实现；不能把这一版称为与两站完全同等功能。已有完整工作台的特殊模型配置也尚未全部迁入画布。

### 拖到空白处添加节点与点阵调整

连线拖至空白处松手，显示文字、图像、视频、音频菜单，选择后在松手位置新增并连接；支持从输入端反向创建上游节点。新增节点及连线只占一次撤销，取消菜单不改动文档；松在节点主体或非画布区域不触发菜单。背景基础间距从 24 提升到 48，缩小时至少保留 32 屏幕像素间距，深浅主题点色均降低对比度。本轮编辑器 20 项测试、类型检查、构建通过；浏览器真实拖拽、选择图像节点和一次撤销验证完成，恢复原六节点画布。截图：output/canvas-drop-add-node.png。
