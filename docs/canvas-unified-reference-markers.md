# 统一素材引用标记（2026-11-08）

根据用户明确要求，画布统一插入、展示 `@ImageN / @VideoN / @AudioN`。绑定仍使用稳定节点 ID，生成前按每种素材实际提交顺序重新编号，不能按画布视觉位置推断编号。

旧画布保存的中文绑定键与 `@图片N / @视频N / @音频N` 继续解析。首次/末尾帧沿用独立帧角色，不伪装成普通参考图。仅显示名称与传输标记变化，不迁移或删除旧画布。

渠道共用映射器同时接受此前的“参考图片N”等文字与新的英文标记；苏打水、LongXia 等已有专属小写协议继续转换，但保留 @。其他直接透传适配器接收画布输出的英文标记，不再由画布统一删除 @。

智赢按用户要求改用英文 @ 格式，并兼容旧中文及从0开始的 ref_N 图片占位符。此项替代 d28af82 的中文输出决策。它是用户要求的格式选择，不能将网页内部接口中文匹配逻辑视作公共 API 英文标记或音色效果已验证的证据。未进行付费生成验证。

FunAI Kling O3 只允许已有前三张元素图的 @Image 标记；第四张起是风格参考，不静默把不支持的 @Image4 当作正常元素绑定。
