## 启用

1. 重启更新后的服务，初始化逻辑会注册这七个模型及其初始价格。
2. 后台渠道管理新增渠道，类型选择 **Haya AI**，Base URL 填写 `https://hayaai.fun`（也兼容末尾 `/v1`）。在服务端后台填写 API Key；不要放进浏览器配置或提交到仓库。
3. 保存时自动绑定七个模型，随后点击模型同步。同步通过 `GET /v1/models` 取七个模型与当前可用列表的交集，不导入文本或其他未适配模型；下架模型不再接受新提交，已有任务仍使用原渠道查询。
4. 检查后台模型启用状态、计费和用户等级权限，在视频页 Haya AI 分组中选择模型。后续模型可用性变化时再次同步渠道。
5. 用一条短任务验证素材上传、进度、成品播放和费用，然后再开启批量任务。真实生成会产生上游费用。

## 素材与参数

- 本站提供 4–30 秒整数时长，分辨率固定为对应型号；Y 截图仅注明自由时长，4–30 秒是本次应用侧支持范围，并非供应商全量能力承诺。
- BZ 截图确认最多 30 张图片、10 个视频、10 段音频。Y 三款确认 30 张图片、0 个视频、10 段音频。
- F、XG 截图没有给出素材上限；目前应用接收上限为 30/10/10，实际支持类型、数量、比例仍须向供应商核对，不能把此上限理解为已确认的上游能力。
- 本地素材和本站 `/uploads/` 素材由后端读取，再逐个上传至 `/v1/files`，保持数组顺序。外部公网 HTTPS 文件直链直接传递，不由本站任意抓取外部地址。
- 单个本地文件不超过 20 MiB；图片宽高各在 300–6000 像素。外部直链的内容、大小和尺寸由上游校验。
- 创建任务使用 JSON 的 `images`、`videos`、`audios`，不向视频创建接口直接发送 multipart 文件；不透传 Base64 或本站相对路径。
- 当前七款发送 `seconds`、`ratio`、`resolution`。首尾帧专用字段未在通用协议定义，明确拒绝；对外 API 拒绝同时传 `size`，避免尺寸冲突。
- 对外 API 支持通过 `metadata` 对象传递模型公开扩展参数。

## 状态和费用

创建前保存本地记录并预扣费用。只有准备开始视频创建 POST 时，才持久化 `hayaSubmissionStarted`；创建请求不自动重试。上传失败和明确的创建拒绝可以退款。创建网络异常、408、5xx、响应损坏或缺失公开任务 ID 时标记为 `review`，保留预扣费用，禁止自动重提或跨渠道补发。

正常轮询为 12 秒，查询异常按 24、48、60 秒退避。状态 `queued` 和 `in_progress` 不因进度停滞或超过旧的 30 分钟恢复超时而判失败；只有任务明确 `failed` 才结算失败。`completed` 后先保存视频到本站，再向用户交付。

保存完整 `metadata.url`，签名链接不携带 API Key；签名链接失效时可尝试带鉴权的 `/content` 接口。下载失败继续查询和保存原结果，不重新生成。

服务重启后：已保存 task ID 的任务继续查原任务；已开始创建但缺失 ID 的任务进入待核实。管理员需使用 request ID、提交时间和 Haya 后台记录核实。文档未提供任务搜索、幂等创建或按业务 ID 找回接口，因此不能自动找回没有保存 task ID 的任务。核实后需补齐原任务 ID 再恢复，或确认未创建后退款；不能直接点击重试创建新任务。

待核实记录有原任务 ID 时，可使用已有管理端任务恢复功能查询。已预扣且未退款的 Haya 任务恢复成功不再次扣费；上游确认失败时原路退款。
