# 无限画布性能整体验收

日期：2026-10-26。对比基线：本地提交 `6be2271`（已经包含前七轮修复），不是最初的线上版本。此次验收覆盖同一分支上全部未发布的画布改动。

## 测试条件与结果

使用本机 Windows Chrome 无头模式、1366×768 视口、生产构建。每种场景分别运行平移、节点拖动、缩放，每种操作两次、每次 60 帧；平移和拖动每帧发送 4 个指针事件。另用真实鼠标拖动，核对最终坐标；输入长文并刷新核对本地存档。素材全部在本地合成，没有调用付费生成或生产数据。

| 场景（CPU 降速 4 倍） | 修改前典型帧间隔 | 修改后典型帧间隔 | 修改前最差一组 p95 | 修改后最差一组 p95 |
| --- | ---: | ---: | ---: | ---: |
| 200 节点 / 199 连线 | 22.4 ms | 20.2 ms | 39.6 ms | 31.3 ms |
| 1,000 节点 / 4,985 连线 | 53.1 ms | 21.3 ms | 71.5 ms | 29.3 ms |
| 200 节点，混合图片、视频、后台任务 | 25.6 ms | 21.2 ms | 49.6 ms | 39.6 ms |

“典型”是六次操作各自 p50 的平均数，不是全站帧率承诺。千节点场景中，360 个采样帧里超过 50ms 的帧由 **205 个降到 0 个**；DOM 元素由 **9,940 降到 2,459**。4 倍降速的混合场景仍有 1 个超过 50ms 的帧；不能将其表述为任何情况下完全无掉帧。

正常 CPU 速度下，上述三组典型帧间隔分别为 **17.0 / 16.7 / 16.8 ms**，最差一组 p95 分别为 28.3 / 19.9 / 23.5 ms，均没有超过 50ms 的采样帧；接近 60Hz 刷新节奏。

混合场景使用 40 张 1920×1080 合成图片、20 个可播放视频节点、20 个模拟处理中任务。操作期间、主动播放前的媒体传输量从约 **9.2 MB 降到 1.5 MB**，视频流请求从 **20 次降到 0 次**；点击后实际播放成功。视频样本为 1 秒合成 WebM，不能代表真实长视频的网络或解码耗时。缩略图网络测试使用已准备好的模拟响应，真实 VPS 首次生成缩略图的冷缓存耗时未测。

## 最终实现

- 保留每帧合并指针操作、独立节点渲染和保存恢复方面的既有修复。
- 节点与连线只绘制视口附近区域。多选屏幕外节点仍能移动、删除或撤销，但不再强制挂载所有选中卡片。
- 超过 300 条连线时使用视口大小的 Canvas 2D 图层；低于 50% 缩放时采用实线，放大后恢复虚线。保留全部连接、曲线方向及实时连线预览，不裁减项目数据。Canvas 上下文不可用时退回 SVG。
- 小地图静态节点与视口指示框分开更新，按类型批量绘制，避免每次平移反复处理上千个小元素。
- 节点、素材库、参考列表和候选图使用已有缩略图能力；失败会回退原图。视频节点显示可用封面，音视频流在播放前不预加载；下载仍使用原文件。
- 相同后台进度不再重复更新文档或触发保存；状态真的改变时仍更新并保存。

## 复测入口

`scripts/check-canvas-performance.mjs` 启动临时本地服务器，生成测试素材并隔离浏览器存储。需要可用的 Playwright、Chrome/Chromium 和 ffmpeg；这些是本地验收依赖，不新增到生产依赖。

构建前端后，从仓库根目录运行：

```powershell
$env:CANVAS_CPU_RATE = '4'
$env:CANVAS_P95_LIMIT_MS = '50'
node scripts/check-canvas-performance.mjs acceptance
```

正常速度复测将 CPU_RATE 改成 `1`、P95_LIMIT_MS 改成 `33.4`。可通过 CANVAS_CHROME 指定浏览器、CANVAS_FFMPEG 指定 ffmpeg；Playwright 不在仓库依赖路径时，用 CANVAS_PLAYWRIGHT_MODULE 指向其依赖目录内的 require 基准文件。CANVAS_CLIENT_DIST 可指定另一份构建作为对比，CANVAS_PERF_OUTPUT 可指定报告位置。性能阈值适用于本次机器条件，其他设备先保留环境信息再比较，不能将环境变慢自动判定为代码回归。

原始本地记录位于 `data/canvas-acceptance-{before,after,normal}.json`，功能记录位于 `data/canvas-acceptance-tests.json`、`data/canvas-acceptance-{long,download,continuous,retry}.log`。同名 PNG 为浏览器截图。
