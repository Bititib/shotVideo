## 初始化与授权

- 启动时一次性存档这两个产品原模型、标准价格和规格，再更新标准价格、渠道归属说明与新规格：720p、5–30 整数秒、16:9/9:16/1:1，最多 30 图/10 视频/10 音频，不支持独立首尾帧。不静默改用户时长、比例或素材。
- 保留原模型数值 ID、公开名称、用户权限、模型和规格启用开关。仅缺失的模型默认停用。标准价格的 720p 分档一并修正为 6.5；后续重启和同步不覆盖管理员后来调价、限制或开关。个人优惠规则保持原机制。
- 只从原来经鉴权同步建立的 KK 线路，或当前 Key 的 `/v1/models` 明确返回 KK 的同步结果绑定新线路。公开目录不是权限依据。KK 原入口是否对用户启用，不影响两个独立旧入口的权限；路线执行 ID 保持各自公开 ID，真实上游 ID 都是 KK。
- 新请求不再走旧 HUSS 支持列表或规格线路。以后同步 HUSS 不会将 BB/HSS 重新加入，后台原 A/B 切换返回明确拒绝并显示 KK 当前来源。HUSS MJ 等其他产品继续原同步。

## 原任务与资金

- 不改 `contents`、原任务 ID、渠道 Key、原请求快照、余额、预扣及退款记录。已接单旧 HUSS 任务从原渠道恢复，即使其参数是 4 秒/21:9，也不会按 KK 参数重建任务。
- 有原预扣/价格快照的未提交批次按原订单金额结算，只有新订单使用新的标准价格。旧批次参数如不在 KK 支持范围内，会明确拒绝，由原批次机制处理，不进行静默改参。
- 网站、外部 API、画布、批次均沿用规格入口；保存任务 ID 后恢复原任务。失败退款与 API 重试继续使用原幂等账本；超时、504、未知受理不重发、不自动退款。
