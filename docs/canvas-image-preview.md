# 画布图片放大查看

2026-11-08，基于 origin/main 的 4dfa661。

原来的图片预览入口在选中工具栏和右键菜单里，预览只适应窗口，没有缩放与拖动。双击节点用于创作，并非图片放大。

本次在有图片的节点上增加常驻“放大查看”按钮，创作面板中的图片参考附件增加“放大”按钮。上述入口及原有图片预览入口统一打开原图查看器，支持按钮/滚轮/双指缩放、拖动、适应屏幕、原始尺寸、关闭按钮和 Esc。加载失败显示错误，不停留在无限加载。

节点仍使用缩略图；打开预览才加载原图。预览变换保存在独立组件中，不写入画布或撤销历史；保留节点双击创作。视频和音频继续使用原来的预览。

验证：画布回归测试 107 项通过；TypeScript 检查及前端构建通过。真实 Chrome 在 1366×768 和 390×844 视口验证 3000×1800 原图的实际尺寸、滚轮缩放、拖动、Esc 关闭及重新打开复位，无页面脚本错误。双指缩放和取消手势使用组件事件测试验证，尚未在实体触屏设备上验证。

本地完成，未推送或部署；线上效果需部署后核验。
