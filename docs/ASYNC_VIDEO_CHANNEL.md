# 异步视频渠道接入

本渠道按所提供的《API对接文档.txt》实现，渠道类型为 `async-video`。

## 后台配置

1. 在「渠道管理」新建渠道，选择「Vx-乐2.0fast（视频生成）」。
2. 默认渠道名为「Vx-乐2.0fast」，Base URL 为用户提供的 `http://38.76.169.75:8080`。填写该渠道的 API Key。Base URL 也支持带 `/v1` 的地址。
3. 保存后点击「测试连接」，再点击「同步模型」。
4. 在「模型路由」检查同步的比例、时长、参考图限制及上游成本，在价格配置中设置本站售价，然后启用模型。

默认渠道和新模型均保持停用，不自动设置售价或把上游 credits 当作人民币。服务地址已配置，仍需要管理员填写用户 API Key 后才可真实联调。启动初始化只在没有此类型渠道时添加默认配置，保留后台后续修改。

## 协议与行为

- 提交：`POST /v1/videos/generations`，Bearer 鉴权，JSON 请求。
- 参数：`model` 使用模型列表中的 `name`，不是数字 `id`；传递 `prompt`、`seconds`、`aspect_ratio` 和可选 `reference_images`。
- 查询：`GET /v1/tasks/{task_id}`，支持 `pending`、`processing`、`completed`、`failed`。
- 完成后额外请求 `GET /v1/tasks/{task_id}/url`，解析 JSON 的 `url`，再将视频保存到本站。
- 解析接口始终使用 API Key，避免依赖五分钟有效的签名 token；下载链接过期时重新解析。API Key 只发往渠道 API，不发给视频 CDN。
- 网页、画布、批量视频和开放 API 通过现有统一模型规格执行。已提交任务恢复时只查询原任务，不重新提交。
- 确认生成失败时按项目现有账本退款；提交超时或响应丢失时保留预扣并标记待核实，避免重复生成。
- 同步模型时保留管理员修改的价格、开关、输入限制和线路覆盖；上游已移除的模型不再匹配该渠道。

## 输入限制

「Vx-乐2.0fast」已预置用户确认的 `b_seedance_v2.0` 模型：最多 9 张参考图、无视频和音频参考、固定 15 秒。模型和路由使用相同限制，提交时再次校验图片数量和固定时长。上游名保持 `b_seedance_v2.0`，本站 ID 为 `async-video-{渠道ID}-b_seedance_v2.0`。无需 API Key 即可注册和编辑，填写 Key 和售价后再启用。

比例和可选秒数使用 `/v1/models` 实际返回值。缺省值按文档采用 `9:16,16:9,1:1` 与 `5,10,15`。

文档没有可选分辨率参数，本站规格使用 `default` 表示由上游决定，提交不传分辨率，不承诺 720p 或其他清晰度。

其他未确认模型的文档未给出参考图数量上限；新规格暂设 1 张，确认渠道容量后可同时调整规格和线路的图片上限。`b_seedance_v2.0` 使用上述已确认的 9 图、15 秒规则，重新同步也不会退回通用默认值。多张图片会完整转发，不截断。视频参考、音频参考及独立首尾帧均不支持。

参考图使用项目现有的素材校验和公网发布流程。火山人脸打码属于文档中的可选外部流程，本次没有调用或硬编码文档中的共享打码凭据；需要时可传入已打码的公网图片链接。
