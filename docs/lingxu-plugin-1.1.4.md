# 灵序 AI 视频插件 1.1.4：只重试原视频下载

生成已完成但视频传输断线或文件长度不符时，旧插件立即抛出异常，宿主因此结束生成流程并显示“重新生成”。新版本让下载重试保持在原 generate 调用内部，完整文件下载成功后返回原 output_position 对应的文件路径，由宿主继续正常回填。

## 行为

- 最多 4 次下载（首次 + 3 次重试），通常间隔 2 / 5 / 10 秒；尊重下载端 Retry-After，各次共用原有 900 秒等待预算。
- 仅 GET 同一个 task_id 的 /v1/videos/:id/content，不调用生成 POST，不新增任务、扣费或退款操作。
- 断线、读取异常、长度不符、空文件、无效 MP4 响应、意外部分响应及 HTTP 408/425/429/5xx 可重试。鉴权、非法地址和本地文件写入错误立即保留具体原因。
- 每次回到原网站下载入口，重新跟随重定向。API Key 只发送给网站同源地址，不发送给跨域视频地址。
- 每次使用独立临时文件；失败清除残片，不返回给宿主，不覆盖已有正式文件。通过原 MP4 文件头和完整长度校验、写盘成功后原子替换正式文件。
- 下载百分比是收到字节占声明长度的比例，并非生成进度。未返回文件长度时不显示百分比；正式文件保存前最多显示 99%。
- 重试期间显示次数、下载量和原因；耗尽后任务记录维持 completed，显示“视频已生成，下载待完成”。查询并取回也使用同一下载重试流程。

## 自动回填范围

宿主任务仍在运行时，下载重试成功后自动回填原分镜。用户取消任务、退出软件或旧版本已经结束的失败任务没有活跃宿主回调，手动取回后仍需使用“找回未记录的生成结果”。本次未改写宿主程序。

## 升级

安装包只含 5 个程序文件，不含 API Key、配置或任务数据库。旧版在线更新器会阻止有待取回任务时更新；如需先修复下载，请保存作品、完全退出宿主，合并覆盖同名插件目录，仅替换程序文件，保留 config.json 和 .state，然后重启。

该修复仅涉及插件；发布目录新增包并更新 latest.json，网站生成和计费逻辑不变。服务器部署本提交后，下载页和在线检查更新才会提供 1.1.4。

## 验证

本地 HTTP 故障注入覆盖：残缺文件 → 连接断开 → 503 → 成功、重试耗尽后取回、同槽位恢复、部分响应、401、429、磁盘空间不足、共享等待预算、多输出槽位和跨域重定向凭据隔离。断线恢复全程验证生成 POST 仅一次，返回文件内容完整且路径对应原分镜槽位。
