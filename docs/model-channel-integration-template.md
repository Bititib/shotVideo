# Codex 渠道接入开发记录模板

本模板由 Codex 按需填写，帮助保存协议依据和代码验证结果；不是用户接入表单或额外审批流程。已有文档或提交说明能完整记录时直接更新，不必重复建表。

## 本次目标

- 用户要求及已授权范围：
- 渠道 模型及变更类型：
- 官方文档及核对日期：
- 无法确认的协议行为：

## 代码事实

- 网站 API 队列 规格及恢复的实际入口：
- 预扣 入队 发送 保存 ID 查询 结算的执行顺序：
- 原问题的触发条件与具体代码位置：
- 此次修改的渠道专属判定及证据：
- 涉及的共用代码及其他渠道隔离方式：
- 公开 ID 内部 ID 上游 ID 的映射：

## 验证

- 能复现原问题的回归测试：
- 实际队列或入口及账本验证：
- 明确拒绝 受理未知 冲突回执 查询异常的结果：
- 防重复生成及扣退款验证：
- 类型检查 测试 构建的真实结果：
- 已有失败与新增失败：
- 真实调用是否执行及授权依据：

## 交付事实

- 修改文件及提交号：
- 是否已推送 是否已部署 是否完成真实验证：
- 对管理员配置和历史订单的影响：
- 尚未解决的问题及原因：
- 仅在必要时说明需要用户补充的信息或操作：
