## 验收清单

- [ ] 文档和脱敏响应足够支持本次判定，无猜测业务规则
- [ ] 公开 ID 不带渠道前缀且无未处理重名
- [ ] 模型能力、素材组合和参数验证正确
- [ ] 同步默认停用，不覆盖管理员价格与状态
- [ ] 成功提交、查询、下载、结算通过
- [ ] 明确拒绝及即时失败任务正确结束，具体原因保留
- [ ] 缺少 ID、回执冲突和发送后断线不盲目重提或退款
- [ ] 查询异常不等同生成失败
- [ ] 恢复和重复执行不造成重复生成、扣费或退款
- [ ] 页面、复制示例、API 列表、价格和请求解析一致
- [ ] 错误脱敏通过，其他渠道无规则串用
- [ ] 相关类型检查、测试、构建完成
- [ ] 已记录真实验证授权、额度及结果，或明确保持停用等待验证
- [ ] 迁移、配置、在途订单及回退影响已核对
