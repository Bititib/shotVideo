# 智赢视频渠道

智赢在本站使用 `zhiying` 渠道类型。管理员在渠道页填写 API Key 后可以测试连接、同步模型。两项操作都只调用 `GET /v1/models`。同步范围限定为下表两个 ID，新产品默认停用，配置本站售价和访问权限后再启用。

| 前端名称 / 本站 API ID | 智赢上游 model | 输出 | 上游积分/条 | 参考图 / 视频 / 音频上限 | 画幅 | 提示词上限 |
| --- | --- | --- | ---: | --- | --- | ---: |
| Lx-Seedance2.5-1 | sd-2.5-fullblood | 720p | 548 | 30 / 10 / 10 | 16:9、9:16、1:1、4:3、3:4、21:9 | 20,000 |
| Lx-Seedance2.5-2 | sd-2.5-fullblood-line2 | 720p | 498 | 30 / 10 / 10 | 16:9、9:16、1:1、21:9 | 45,000 |

两款均支持文本生成、5 至 30 整数秒，默认 30 秒、16:9。两条满血专线按各自的 ID 选路。本站报价、预扣和结算使用管理员配置的价格。渠道返回的积分用于记录上游成本。协议依据为[智赢模型目录](https://zhiyingai.xyz/api/docs)和 [OpenAPI 2.1.0](https://zhiyingai.xyz/api/openapi)。

渠道编辑页显示两条专线的预设对应关系。点击「同步模型」后，本站为目录确认可用的型号写入上游映射和执行线路。若智赢返回某条专线不可用或字段矛盾，同步会列出该线路的原因，并继续处理其余可用线路。重新同步可恢复上游已开放的线路。

## 调用

网站视频页、画布和视频批量使用本站既有入口。外部客户端用本站 Key 提交 `POST /v1/videos`，保存返回的本站任务 ID，再查询 `GET /v1/videos/{id}`。例如提交专线 2 的五秒视频：

```json
{
  "model": "Lx-Seedance2.5-2",
  "prompt": "清晨，一只水鸟掠过湖面。",
  "seconds": 5,
  "resolution": "720p",
  "aspect_ratio": "16:9"
}
```

本站模型目录、报价、任务回执和调用示例统一返回 `Lx-Seedance2.5-1` 或 `Lx-Seedance2.5-2`。旧调用 ID 仍可作为兼容输入，沿用原来的价格、授权和订单。相同请求在新旧 ID 间切换时仍复用原有去重记录。

客户端按本站原格式传参考图、视频和音频。服务端按类别和原顺序上传素材到智赢 `POST /v1/files`，用返回的文件 ID 构建最终请求。官方列出了 HTTP 201，上传成功响应的 JSON 包装仍待账号联调确认。目前读取顶层 `id` 或 `file_id`，两者都有时须一致。回执缺失或格式冲突会在付费生成前结束并退回预扣。只有 `POST /v1/generations` 创建付费任务。

满血专线 1 的参考视频时长按实际上传文件探测，再填写 `reference_video_duration_total`。专线 2 使用该线路自己的参数表。Studio 的素材入口支持图片，视频和音频参考可通过视频生成页、批量或外部 API 提交。

## 回执、恢复与费用

- 发送生成请求前保存原渠道、凭据指纹、幂等键和已上传文件组成的请求快照。关联原任务 ID 后始终通过 `GET /v1/generations/{task_id}` 检查进度。
- 上游返回 `created`、`queued`、`processing` 或 `review` 时继续查询。查询暂时失败或已生成结果的签名链接过期时，保留原订单、预扣和任务编号。下载外部签名链接时只使用签名链接自身。
- 创建断线且缺少 ID 时，恢复逻辑核对原预扣、原渠道、凭据指纹和快照。仅在首次付费发送后的 10 分钟内，以同一幂等键和请求体最多恢复 3 次。超出本站窗口或遇到幂等冲突则保留原单核对；已有任务编号始终优先查询原任务。更换凭据后，旧单恢复需要原凭据。
- 上游明确拒绝或任务确认失败时，由对应的本站账本处理退款。即使打开批次自动重试，已确认失败的智赢任务也结束并通过批次账本退款。上游返回的 `refunded` 单独记录。

公开文档没有给出幂等记录保留期限。缺少可安全重放证据的历史单应核对智赢调用记录。登录账号实际返回的目录、积分和生成结果以联调为准。
