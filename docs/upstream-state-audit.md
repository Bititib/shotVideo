## HM Studio：依据用户提供的接口约定

- 正常提交：HTTP 202，task_id；查询 /v1/tasks/{task_id}。
- HTTP 400：参数错误或渠道关闭；401：鉴权；402：积分；429：限流或 GENERATING_LIMIT。
- HTTP 503 且完整 error 字符串：繁忙拒绝，结束本次订单并退款。HTML 网关响应或无法读取的正文不套用此业务拒绝规则。
- 用户反馈的“临时修复”维护拒绝单独识别，只检查错误字段或完整短文本，不搜索提示词及任意嵌套字段。
- 普通 HTTP 500 内部错误不能证明未创建任务，仍需核对；与维护拒绝分开。
- 同时出现任务回执或已受理状态时，不因错误文字退款或重新提交。
- 查询 status=failed 与 fail_reason 是任务失败；查询请求失败不是任务失败。

实现：hmStudioSubmission.ts；HM 队列、规格视频与规格图片提交使用该判定。
修复队列 catch 没有传递“明确拒绝”的问题。临时并发限制不再永久关闭渠道或 Key。
