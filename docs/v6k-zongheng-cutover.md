# 纵横科技仅使用 V6K 视频接口

旧的视频协议已移除，不再调用旧站提交、/v1/tasks 查询或 /v1/media 上传。

## 上线配置

1. 更新启动后，原纵横渠道统一为 V6K 类型。使用旧站地址的渠道自动改为 https://www.v6k.top 并暂时停用，避免将旧站密钥当作新站凭据使用。
2. 首次启动会归档并移除旧站模型、旧站售价、模型映射与旧销售线路。历史任务、余额、账单、成品文件不变。归档位于数据库内部的 v6k_retired_configuration，不出现在模型管理中；迁移仅执行一次。
3. 后台编辑原渠道，填入 V6K 站点创建的新令牌，测试连接并同步模型，核对精确模型 ID、时长、分辨率及售价后启用。
   同步以携带令牌的 /v1/models 为权限依据，结合新站公开 /api/pricing 的视频端点分类；不会仅凭名称猜测视频模型，不会从公开目录导入当前令牌无权使用的模型。
   新模型默认停用，不创建旧站默认价格，也不把上游价格自动作为本站售价。已设置的新站价格和启用状态在后续同步、重启时保留。
4. 如模型使用销售路由，核对线路所用渠道 ID。原渠道记录 ID 保留，不需要重建账单或删除历史记录。
5. BACKEND_URL 使用本站公网 HTTPS 地址，确保 /reference-assets/ 可由上游读取。参考素材使用随机名称的稳定文件链接。

## 新站型号与规格

shared/zonghengVideo.ts 仅保留 2026-10-24 从新站模型广场核对的规格，不再包含 QQ、KK、旧拼写 TTsedanco2.5-480 等旧站规格。新站的准确拼写是 TTseadanco2.5-480。
已确认的 TT 2.5 支持 5–30 秒，按具体 ID 固定 480p、720p 或 1080p；Fast/2.0 线路通常为 5–15 秒、9图3视频3音频；dola2.0 固定15秒，dola2.5 为5/10/15秒；Grok 为5–15秒、最多5图，支持16:9/9:16/1:1。
每个型号仍按各自配置校验，不能将某个型号的上限套用于整个系列。目录里尚未明确说明规格的型号只同步为停用配置，需管理员在模型规格中补齐后启用，不能沿用旧站参数。

## 历史订单

已完成的视频、历史失败记录及账单均保留。未完成的旧协议任务停止自动查询并显示待核实，保留任务 ID 和原扣款，不自动重提或退款。管理员核实原结果后处理；不能假设旧任务 ID 在新站可用。

## 新任务

- POST /v1/videos，使用 seconds/images/videos/audios，保存返回的 id。
- GET /v1/videos/{id}，识别 queued/in_progress/completed/failed，通常每 20 秒查询，临时错误退避并尊重 Retry-After。
- GET /v1/videos/{id}/content，由服务器携带新站令牌下载并保存；浏览器和其他下载域名不会收到令牌。
- 明确提交拒绝或任务失败只退款一次；查询和下载错误继续处理原任务。504、断网或缺少 ID 且接单结果不明时待核实，禁止自动重提。
- 文档未确认首尾帧、quality、negative_prompt、generate_audio；这些选项会在生成前明确报错。

文档：https://www.v6k.top/docs?guide=unified&category=video

测试使用模拟上游和独立数据库；真实权限和付费生成链路需要上线后使用新站令牌验证。
