灵序 AI 视频插件 1.1.0 配套网站改动
基线：origin/main 8ba4649，保留最新四个 WAN 型号和旧型号下架逻辑。独立工作区修改，未覆盖其他任务未提交的代码。

交付范围
1. /v1/models 的视频记录返回 capabilityVersion:1、canonical_id、description、routingLimits、parameterSchema。
2. /api/video/models 使用同一能力定义，保留原有列表可见性、定价和启停策略。
3. /v1/videos 接收 model_parameters 对象；multipart 中为 JSON 字符串。入口在预扣和任务创建之前验证类型与约束。
4. 统一规格路径同样校验；Wan prompt_extend 已从规范化请求传入真实规格适配器，false 不会被丢弃。
5. /plugin-updates/video_plugin_site_api/latest.json 和版本 ZIP 公开提供，清单禁用缓存；Docker 生产镜像包含 plugin-releases。

新模型与特殊参数
网站接入模型时在真实适配器核实参数，并在 server/services/videoCapabilities.ts 的 VIDEO_PARAMETER_SCHEMAS 声明。
参数采用 JSON Schema 的有界子集：type 为 string、integer、number 或 boolean；支持 title、description、enum、default、minimum、maximum、multipleOf、minLength、maxLength 和顶层 required。
声明之外的对象、数组及条件式参数需要扩展契约和插件版本，不能通过描述文字猜测。
参数名保持稳定，必须由实际适配器消费。给出定义并不等于上游支持，不能只添加定义就宣称适配完成。
当前额外字段是网站现有四个 WAN 型号的 prompt_extend，与最新适配器一致。当前 V6K 明确拒绝的负面提示词、质量、音频开关不予发布。
多个启用路由仅发布定义一致的字段交集，避免换路由时静默丢参。
时长、分辨率、比例和素材上限优先取统一规格；旧模型取已有适配器约束。不用名称猜测；旧规格草稿中的默认比例不作为已验证的比例发布。
插件保存值按型号与账户隔离，变化时保留原值并提示重新选择；旧字段需主动清除。

后续发布插件版本
1. 更新插件 main.py 的 VERSION、info.json 的 version 和界面版本显示，制作只含五个程序文件的干净 ZIP。
2. 执行 python scripts/stage-plugin-release.py <ZIP路径> --notes "本版更新说明"。
3. 程序先放入版本 ZIP，再更新 latest.json。不要修改已经发布的同版本 ZIP 内容。
4. 使用现有网站发布流程部署，Dockerfile 已包含更新目录；不会读取或覆盖 data、.env 或数据库。
5. 检查线上 latest.json 中版本、大小、SHA-256 与 ZIP 一致。用户安装 1.1.0 后即可自动检查并点击升级。
更新信任固定 HTTPS 发布域名及网站管理员；SHA-256 校验防止传输损坏，不是独立的离线签名机制。

之后点击升级前检查本地运行锁与未完成任务；下载校验后备份原程序，逐个原子替换。
失败或中断恢复旧版，保留上一版备份供回退。代码与数据分离；不迁移或删除用户任务数据库。
