# HUSS 同步遵守管理员删除记录

2026-11-20

后台渠道同步经 ChannelService.syncModels 进入 syncHussModels。此前该服务未读取
settings.deleted_model_ids；上游仍列出渠道 A 时会重建已删除的 BB/HSS 模型与规格，
旧的来源选择记录也可能重新写入渠道关联。

现在在上游目录返回后、数据库事务内读取删除记录：

- 创建/更新模型及规格前过滤已删除的公共 ID。
- 来源选择回填同样跳过已删除 ID。
- 删除记录格式异常时中止同步，不将其误当空列表。
- 不硬编码禁用 BB/HSS；管理员显式重新添加并解除删除标记后仍可正常配置。
- Midjourney 同步继续保留已有售价、启用状态和线路开关。

不修改上游提交、查询、下载、历史订单、资金或其他渠道同步。
这不是批量删除迁移，部署前已删除模型应有 deleted_model_ids 标记；前述 VPS 删除脚本已写入该标记。

验证：HUSS Midjourney、HSS 视频、迁移测试共 67 项通过，包含重复同步、旧来源回填、
同步等待期间删除、异常删除记录及 Midjourney 价格和状态保留；前端构建通过。
全项目类型检查受本地依赖缺失阻塞：yauzl、pdfjs-dist、mammoth（聊天附件模块）；
未修改这些模块及依赖清单。未执行生产部署或付费生成。
