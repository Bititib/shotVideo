# HSS 原渠道 / 新渠道切换

后台模型管理编辑 `hss-2.5-301010`，点击“原渠道B”或“新渠道A”立即保存。原渠道为 `hss-2.5-301010-渠道B`，新渠道为 `bb-2.5-301010-渠道A`。无需再点击模型弹窗的保存按钮；切换失败保留原选择。

切换在一个数据库事务中修改当前 HSS 规格的 HUSS 线路及该公开模型的映射，保存手动选择。后续同步模型保持此选择。不会修改 BB、MJ、用户售价、模型/渠道启用状态或历史订单。若存在其他启用的混合线路则拒绝切换，要求先核对，避免声称固定渠道却实际走其他线路。未配置线路时要求先同步。

切换使用目标渠道已有能力定义；切换到不同上游时清空旧线路成本标记为未知，避免将 A 成本当作 B 成本；用户售价保持原值。线路关闭状态保留。已有任务的原渠道、上游编号、请求快照和账本不改写，恢复继续查询原任务，不重新生成。切换不保证原渠道仍在线或密钥仍有该模型权限，上游明确拒绝按已有适配器返回。

验证：81 项切换、迁移、HUSS 提交适配和恢复相关测试通过；实际路由选择在 A/B 间切换、同步保持选择、BB/售价不变、关闭线路不意外启用、原选择快照保持及 UI 保存失败回显均覆盖。类型检查及构建通过。未执行生产切换或付费调用。
