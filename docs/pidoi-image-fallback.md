# Pidoi 图片同步优先

默认同步提交：文生图 `/v1/images/generations`，图生图 `/v1/images/edits`，后者上传图片文件。网站仍由后台保存和结算，浏览器不必等待生成响应。

同步接口明确不存在或不支持方法（404/405），且没有任务受理凭证时，每张图最多切换一次 `/v1/image/generations` 异步备用。超时、断网、5xx、参数或权限错误不会触发第二次生成；备用失败不循环切回同步。

备用提交前，在原内容记录 `pidoiFallbacks` 中记录执行状态；复用原任务、预扣账本和恢复流程。后台详情显示同步生成或异步备用，并保留备用任务 ID。已取得图片后的下载失败只重试下载。旧任务继续查询原 ID，不因更新重新生成。

保留现有 `PIDOI_IMAGE_REQUEST_MODE=async-first` 显式配置；未配置时同步优先。保留已发布的同步最长 15 分钟、自动恢复 30 分钟暂停规则；同步传输等待也使用该生成期限，不再被客户端默认等待时间提前截断。

本地回归测试使用模拟上游响应，不会发起真实付费生成。

## 管理员补录已生成图片

Pidoi 网页图片任务处于待核实且本站没有成功结果时，后台详情可「补录成功图片」：填写属于原订单的全部图片直链（HTTPS，每行一条），点击「保存图片并恢复成功」。入口为 `POST /api/admin/contents/:id/image-supplement-result`，请求体为 `{ "urls": ["https://…"] }`，需要有效的超级管理员登录。

此操作只下载原图片，不调用生成接口。使用已有图片保存器校验公开地址、大小、图片类型并登记原用户的图片访问权限。全部图片保存成功后，在事务中将原预扣账本结算、订单置为成功；原费用保持不变，不新增扣款。审计字段 `pidoiResultSupplement` 记录操作者、时间、数量、账本和原待核实原因。不能用补录覆盖已有成功结果，也不恢复已退款订单或处理规格/API/批量任务。

下载与校验失败不改变订单和预扣；下载期间禁止同任务补录、恢复和退款并发，提交事务前再次核对账本与订单防止覆盖其他处理。重复补录已完成记录只返回已处理，不重复下载、生成或扣费。服务器部署后才会显示该入口；本地实现不等于历史订单已恢复。

## 管理员补录上游任务 ID

协议依据：2026-10-27 实际读取 [Pidoi 官方图片异步任务查询文档](https://pidoi.com/docs/api?doc=image-generation-async-query)。文档确认 Bearer API 令牌、`data.task_id`、大写状态 `IN_PROGRESS / SUCCESS / FAILURE` 和 `data.result_url`。404 同时可能表示任务不存在或不属于当前用户；不能据此认定生成失败。文档允许同一用户其他有效令牌查询，额度耗尽或过期令牌仍可只读查询，禁用令牌/用户不可查询；本功能不自行切换账号。

单图待核实订单支持「补录上游任务 ID」→「查询原任务并恢复」。使用 `POST /api/admin/contents/:id/image-supplement-task`，请求体 `{ "taskId": "上游原任务编号" }`，只允许有效的超级管理员操作。编号不要求 `task_` 前缀，拒绝占位文字、链接和其他订单已绑定的编号。

查询复用原渠道与 Pidoi 适配器的 `GET /v1/image/generations/:id`，不调用生成接口、不换渠道或另一个账号。先核实响应的任务编号与输入一致，再保存已验证回执；查询返回 401/403、404、网络异常、未知状态或编号不匹配时，不绑定编号、不改变订单和预扣，管理员可以更正编号、核对原渠道密钥或使用既有确认失败退款入口。上游鉴权错误通过本站 502 响应展示原始脱敏诊断，避免被浏览器当作本站登录失效。

成功回执在下载前持久化，下载失败或进程重启后由原恢复器继续保存，不重复查已拿到成功链接的任务。进行中回执交给后台继续查询原任务；明确失败按原预扣账本幂等退款；成功图片落盘后按原金额结算，不再扣款。批量/规格/API 订单不在此入口范围，多图订单使用全部图片链接补录。生产 #14506 的实测仍为 HTTP 401 `Invalid token`，未证明该编号可查、未修改其生产状态或余额；新增入口不能绕过上游鉴权。

文档所述 `IN_PROGRESS + recovery_required=true` 明确要求人工核对，保留原编号与预扣并暂停自动查询，不重提、不自动退款。成功图片若为原 Pidoi 同源的 `/v1/image/generations/{原任务ID}/content?index=N`，下载器仅向该精确任务路径携带原密钥，禁止重定向；其他 CDN/签名直链不携带 API Key。下载保持 60 秒和 20MB 上限，并经过现有 PNG/JPEG/WebP 校验与原用户访问权登记。

本地验证：8 个相关测试文件共 147 项通过，覆盖真实网站预扣入口、后台补录路由、恢复器、账本、权限与 UI；类型检查和前端构建通过。未执行真实付费生成或生产恢复。
