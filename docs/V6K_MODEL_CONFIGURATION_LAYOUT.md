# V6K 模型配置布局调整（2026-11-08）

## 当前操作方式

针对「添加、切换模型步骤不清楚」调整为左右工作区：左侧搜索和选择已有模型，上方独立「添加新模型」按钮；右侧标题标明添加或编辑状态。手机上用「切换模型」选择器操作。

- 新增：点击「添加新模型」，填写本站 API ID、显示名称、上游完整 ID，设置规格与素材上限，点击「校验授权并添加模型」。成功后选中新记录并提示到关联模型列表设置售价、启用模型总开关；不自动上架。
- 编辑：点击左侧模型卡片或使用搜索。本站 API ID 保持只读，保存按钮标为「校验授权并保存修改」。保存后列表保持服务端顺序，重新读取同渠道配置版本，避免随后编辑其他模型时使用旧版本。
- 当前有未保存修改时，切换或关闭先提示，可继续编辑或明确放弃。预览、搜索、选择模型均不会保存配置。保存成功后若列表刷新失败，仍报告保存成功并提示重新打开，不把刷新异常误报为保存失败。
- 常用规格由表格改为表单，素材合计上限等额外约束折叠到「更多素材限制」。请求体和线路 JSON 仍可查看。

验证更新：相关界面测试 21 项通过，排除下文注明的既有 HM 定价用例；类型检查、生产构建通过。浏览器使用本地内存示例实际验证新增、未保存切换提醒、添加后反馈及 390px 手机选择器；未保存生产配置、未调用上游生成、未操作订单或资金。

本次继续使用原配置保存和授权检查服务。新增加的列表刷新只读取配置，没有修改提交、轮询、计费或退款调用链。
