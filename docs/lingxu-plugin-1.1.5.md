# 灵序 AI 视频插件 1.1.5：断点续传

## 变更

保留 4 次下载尝试与原任务 ID，增加按账户、任务和输出文件隔离的持久化断点。下载仅使用 GET；不修改提交、计费或退款行为。

网站 `/v1/videos/:id/content` 与视频文件代理入口为实际交付文件提供强 SHA-256 ETag，通过原 sendFile 处理 Range / If-Range。散列以文件身份、大小和修改时间缓存，文件变化后失效；计算过程中变化会停止交付。返回 no-transform，避免传输层改写字节。

插件续传只使用强 ETag。保存的断点包括已落盘字节数、总长度、ETag、本地前缀摘要及任务身份摘要，不含账户密钥或签名 URL。每 MiB 与中断退出时保存校验过的进度；加载时验证摘要，截去未提交尾部。请求从原下载入口开始，跨域跳转不发送 API Key。

- 206：严格校验起始偏移、总长度、ETag 和响应段长度后追加。
- 200：服务忽略 Range 或文件变化，截断临时文件并安全接受完整新文件。
- 416、错误范围或校验不符：丢弃无效断点，后续尝试从头取原视频。
- 弱 ETag、没有可靠总长度：不拼接残片，保留旧版本完整下载兼容行为。
- 下载完成后校验 MP4 文件头、完整长度；网站 SHA-256 ETag 还用于核对最终文件内容。原子替换正式视频后清理断点。

实现依据：[RFC 9110 §13.1.5 If-Range](https://www.rfc-editor.org/rfc/rfc9110.html#section-13.1.5)、[§14 Range](https://www.rfc-editor.org/rfc/rfc9110.html#section-14)。不使用弱校验标识发起 If-Range。

## 验证和限制

本地 HTTP 测试覆盖连续中断、进程间恢复（新客户端）、服务忽略 Range、远端文件变化、416、错误范围、本地残片修改、未提交尾部、账户隔离及既有重试/原任务恢复；校验生成 POST 次数与返回原输出槽位的文件字节。

网站测试通过真实 v1 下载入口验证强标识、正确 206 剩余数据、If-Range 不匹配时完整 200、416 和不新增任务/费用。配套检查视频兼容处理及公开响应隐私；类型检查通过。

生成中的宿主回调在续传期间保持活跃，完成后照常返回文件供回填。已经结束/取消的旧宿主任务没有活跃回调，手动取回后仍需找回未记录的生成结果。没有对其他用户电脑做现场回填，也未创建真实收费任务。

发布包含新版 ZIP 与远程清单。管理员部署后网站才提供安全续传标识与 1.1.5 在线更新；旧服务继续采用安全的完整重试。升级保留配置、任务数据库及作品旁的断点。
