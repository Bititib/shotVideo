# 画布节点直接下载

2026-10-25。在输入框扩大调整之后继续改善节点操作。

- 有素材地址的图片、视频和音频节点底部常驻显示带文字的下载按钮，无需选中或前往右上角。没有结果的节点不显示下载。
- 按钮阻止指针/点击事件冒泡，不拖动节点、不打开创作面板、不触发生成。
- 复用 `downloadNode`；私有 `/api/media/` 继续经已有鉴权下载辅助函数。普通视频地址改用视频页面已经使用的 `/api/video/download` 附件接口，避免浏览器忽略跨域 `download` 属性而直接播放；data/blob 地址保持本地下载。服务端下载权限和接口均未改动。
- 节点底部为按钮增加空间，支持深浅主题和键盘焦点。

验证：新增 5 项节点下载用例，连同已有创作面板/定位用例共 16 项通过；类型检查及生产构建通过。真实 Chrome 在 1920×1080、1366×768、390×844 渲染生产构建，节点按钮可见；以本地模拟下载响应验证浏览器下载事件及文件名。没有访问真实上游、付费生成或部署生产；模拟下载不代表已验证每个生产视频源。
