# 独立 API 模型列表展示页面

更新日期：2026-11-05。

独立页面为 `/app/models`，直接渲染 `ApiModelsPage`。`/models` 是便于分享的短入口，跳转至该页面。访客可查看公开型号、规格和调用示例。有效登录会话可查看标准价格，创建 API Key 后可按 Key 查看授权目录及个人价格。

入口包括首页顶部导航、首页页脚（移动端也可访问）、工作台侧栏“模型列表”，以及API 文档的“独立查看模型列表”。页面提供完整标题、Base URL 复制、搜索、模型类型筛选、价格、能力规格、状态、模型ID复制和调用示例，保留返回接口文档的链接。

原 `/app/docs?tab=models` 标签页使用相同列表组件。访客目录读取 `/api/developer/models/public`，服务端只提供结构化规格，不返回金额和可能写有金额的自由文本说明。默认登录目录读取受会话保护的 `/api/developer/models/standard`，响应设置 `private, no-store`。选择 Key 后使用既有授权目录，退出时丢弃含价格的目录及详情。

路由回归直接渲染真实 App、Layout、首页、API 文档和模型列表（接口使用模拟响应），验证匿名直接访问和短链接、首页/页脚入口、侧栏选中、旧文档入口、返回文档，以及没有 API Key 的登录账号可访问。原列表测试继续覆盖搜索、示例复制、私有Key切换和迟到请求隔离。
