# 万字提示词编辑

2026-10-26，继输入区扩大与节点下载后，按上万字长文需求调整。

- 普通面板最大宽度 900px，桌面输入区默认高度 320px，手机 240px。
- 默认字号 18px，可选 16/18/20px，字号偏好保存在本机。
- 增加「展开编辑」，独立固定编辑窗口最大宽度 1280px、高度随视口变化，素材卡片不挤占编辑区。
- 使用同一个受控 textarea，展开/收起不重建 DOM，保留正文、光标和原生撤销记录；修改沿用原画布草稿保存机制，不增加保存副本或确认提交。
- 提供文字/镜头编号查找，循环定位下一处并滚动到匹配行；保留 @ 素材引用。查找不会修改正文。
- 编辑模式使背景控件 inert，键盘焦点限制在编辑区；Esc 先关闭引用菜单，再退出长文编辑。关闭后恢复背景可交互状态。
- 不新增前端文本截断；编辑能力不代表任何模型均支持万字请求。生成校验、上游协议、扣退费路径保持原样。
