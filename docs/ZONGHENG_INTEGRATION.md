# 纵横科技：旧版渠道接入

本次基于 `文档.txt` 接入现有旧版渠道体系，使用渠道、模型、模型映射、价格、余额预扣、内容记录及视频恢复流程。未为纵横科技建立新版模型规格或销售路由，也未改动新版路由服务。

## 后台配置

1. 在“渠道管理”新增渠道，类型选择“纵横科技”，地址填写 `https://cnd-coo-new.pages.dev`，添加该渠道提供的 API Key。
2. 测试连接并同步模型。同步使用 `/v1/models`，只读取该 Key 获授权的公开模型。
3. 同步后的本站模型 ID 为 `zongheng-<公开模型 ID>`，模型映射保留原公开 ID。例如本站名称带前缀，请求渠道时自动去掉前缀。不要改为上游隐藏模型名。
4. 新同步模型默认停用。根据渠道能力中枢核对模型分类、时长、比例、分辨率和素材支持范围；现有自动分类仅供初始配置参考。
5. 在旧版价格管理中配置对应模型价格，再启用模型及用户/API Token 权限。图片需要配置按次价格；视频沿用旧版按次或按秒计价；GPT 沿用输入/输出 Token 价格。价格和真实模型能力未在所提供文档中明确，不能使用测试中的样例价格。

此次没有创建实际渠道配置、写入真实 Key 或启用真实模型。无需数据库结构迁移。

## 视频

- 网页、批量生成及开放 API 沿用原入口；开放 API 创建路径为 `/v1/videos`，也保留项目已有兼容入口。
- 对外返回本站 `task_<内容编号>`，按照响应中的 `status_url` 查询。内部保存渠道返回的 `vid_...`，始终回到原渠道查询 `/v1/tasks/{任务 ID}`。
- 参数映射：`duration` / `video_length` → `duration`，`aspect_ratio` → `ratio`，`resolution` → `resolution`，`images` / `reference_images` → `images`，视频和音频参考分别映射为 `reference_videos`、`reference_audios`，独立首尾帧映射为 `start_frame`、`end_frame`。同类素材不要同时使用多个别名；普通参考图不能与独立首尾帧混用。
- 仅传文档中的平台字段，包括可选 `quality`、`negative_prompt`、`generate_audio`，不透传 `extra` 或上游专用参数。
- 本站上传文件或 base64 素材在提交时上传 `/v1/media`，每个文件最大 25MB；支持文档列出的图片、音频、视频格式。渠道素材有效期 3 天，本地素材会重新上传，不复用缓存过期链接。外部素材必须为公开可读取的 HTTPS 文件直链。
- 使用持久化业务订单号作为 `Idempotency-Key`；不会自动重发结果不明确的创建请求。超时、服务异常或提交后未得到有效 ID 时转待核实，并保留预扣费用；明确拒绝或任务明确失败时沿用退款流程。
- 轮询遵循 `next_poll_seconds`；查询临时故障继续查询原任务。只有 `succeeded` 才读取结果地址，下载时保留原地址、不附带渠道 Key。重启恢复及管理员补救沿用原任务，不重复扣费。

具体模型是否支持多图、首尾帧、音频或视频参考仍以渠道能力中枢为准。网页和画布保留旧版按模型配置展示控件的规则；未知模型的全部素材模式不会因接入协议而自动出现在页面中，可通过开放 API 使用已经确认支持的参数。

## 图片

- 网页 `/api/image-gen/generate`、开放 API `/v1/images/generations` 已接入，单次 1–4 张；按实际返回张数结算。
- 未提供 `size` 时，按比例和 1K / 2K / 4K 长边生成尺寸，边长取 64 的倍数。网页默认 2K，开放 API 默认 1K；开放 API 的 `output_resolution` 或 `resolution` 同时用于旧版对应档位价格。明确传 `size` 时按原值发送，并应填写相符的计费分辨率。
- 当前文档只明确文生图；参考图、蒙版和图片编辑请求在扣费前拒绝。支持开放 API 的 `url` / `b64_json` 输出。
- 渠道图片 URL 有效期 24 小时，收到结果后立即保存到本站。提交结果不确定或已生成但本地保存失败，记录转待核实并保留费用及可用的渠道结果信息。

## GPT

使用旧版 `/v1/chat/completions`，支持普通响应和 SSE，沿用原 Token 计费流程。本次没有新增 `/v1/responses` 或修改网页现有 Gemini 分析流程。渠道自身的缓存 Token 积分规则与本站旧版两档 Token 售价不同，本次未新增缓存 Token 单独售价。
