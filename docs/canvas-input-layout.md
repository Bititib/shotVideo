# 画布提示词输入区域扩大

以下为第一轮调整记录。2026-10-26 已进一步按万字长文需求升级，当前尺寸与交互见 [万字提示词编辑](canvas-long-prompt-editor.md)。

2026-10-25，基于 main `11ef17a`。

- 桌面创作面板最大宽度由 550px 调整到 760px；窄屏继续预留左右 12px。
- 桌面提示词默认高度由 105px 调整到 220px，字体从实际生效的 11px 调整到 14px。支持竖向拖动，最大 420px。
- 手机默认高度 180px、字体 16px，输入区和面板正文滚动高度随视口限制。手机面板层级高于左侧工具栏，防止工具栏遮住输入文字。
- 打开面板和聚焦节点时读取面板实际高度，避免首次 ResizeObserver 回调前用旧高度计算，导致放大的面板在笔记本屏幕底部被裁切。仍在节点下方居中，不在用户拖动画布时自动重新定位。

验证：TypeScript 检查、Vite 生产构建通过；现有创作面板、草稿保留和节点定位相关测试 11 项通过。使用真实 Chrome 渲染生产构建，模拟本地模型目录（无生成请求），检查 1920×1080、1366×768、390×844：面板及底部操作按钮均在视口内，输入区域尺寸与字体符合预期。截图存于本地忽略目录 data/canvas-input-*.png。

首次构建在产物生成后遇到 Node 24.14 退出断言，改用已安装的 Node 24.22 重新构建正常退出。生产环境尚未部署。
