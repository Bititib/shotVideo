# TT Seedance 2.5 三档清晰度合并展示

更新日期：2026-10-31。

视频生成页把 `TTseadanco2.5-480`、`TTseadanco2.5-720`、`TTseadanco2.5-1080`（包括已有 `ZH-` 名称）合为一张“TT Seedance 2.5”卡片，显示各清晰度实时售价。卡片描述压缩为清晰度、时长区间及素材上限，不再重复列出5到30秒的每一个数字。

这是前台展示分组，不创建新销售型号、不合并数据库订单或价格。原 API 型号、API 文档目录、画布/批量入口、权限、任务ID、提交去重和结算机制保持原样。用户在视频页选择清晰度时，同时切换为该清晰度真实型号，报价、规格校验、提交和历史记录仍使用真实型号。旧订单复刻与恢复继续按原型号和元数据读取。

价格从实际模型列表读取，不写死0.28/0.4/0.9，也不覆盖管理员或用户价格。卡片状态指示对应当前清晰度的真实型号。不可用的清晰度在选项中禁用并显示“暂不可用”，不把其他档位的可用状态套用过来。只有同计费方式、同素材和时长约束、每档清晰度唯一的型号才合并；存在不同规格或重名价格时保留独立卡片。按条计费的 `TTTseadanco2.5/720` 不属于此组。

实际调用链：原 `/api/video/models` → 保留原始 `models` → `groupTt25ModelCards` 生成展示卡片 → 分辨率选择同时设置真实 `selectedModel` 和 `resolution` → 原 `useVideoQuote` / `generateVideo`。不向服务器提交展示分组名。
