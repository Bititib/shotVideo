灵序 AI 视频插件｜安装与更新说明（1.1.2）

新版下载：
https://video.zhubo.asia/plugin-updates/video_plugin_site_api/lingxu-video-1.1.2.zip
网站：https://video.zhubo.asia

一、第一次安装
1. 下载压缩包，解压得到 video_plugin_site_api 文件夹。
2. 保存作品，彻底退出字字动画。
3. 将整个 video_plugin_site_api 文件夹复制到：
   字字动画安装目录\_internal\user_resources\plugins\video_plugins\
   最终应能看到：
   video_plugins\video_plugin_site_api\main.py
   不要只放压缩包，也不要多套一层同名文件夹。
4. 重新打开字字动画，进入作品 → 视频模型管理 → 自定义插件，选择“灵序 AI 视频插件”。
5. 在网站个人中心创建自己的 API Key（https://video.zhubo.asia/app/profile）。展开插件“网站连接”，地址填写 https://video.zhubo.asia，填入该 API Key，点击“连接并获取模型”。
6. 选择视频模型及其支持的时长、分辨率、画面比例和特殊参数，点击“应用设置”。
7. 回到分镜填写视频提示词、添加参考素材，再点击分镜旁的“生成视频”。

上述目录适用于已验证的 Windows 字字动画安装包。若安装目录中没有 _internal，请先确认当前版本的插件目录，不要随意创建多层目录。
安装包不附带 API Key。生成需要账户具有对应模型权限和足够余额，费用以网站显示为准。

二、已经装过插件，怎样更新
1. 先等待生成、取回等任务结束；若任务记录提示处理中、待核实或待取回，请先处理原任务。
2. 打开“灵序 AI 视频插件”设置面板，找到“插件更新”：
   · 1.1.0 / 1.1.1：在面板底部。
   · 1.1.2 起：在面板最上方，默认展开。
3. 点击“检查更新”，发现新版后点击“升级到新版”。
4. 提示安装成功后，保存作品，彻底退出并重新打开字字动画。
5. 再次打开插件，确认版本为 1.1.2，或网站当前发布的更新版本。

插件会自动检查新版，但不会未经点击自行安装。远程升级保留 API Key、用户设置和任务记录。
安装新版本后若需恢复旧版，可在“插件更新”中点击“回退上一版”，然后重启字字动画。

三、没有“插件更新”，或远程更新暂不可用
1. 下载上方完整安装包。
2. 等任务处理完，保存作品并退出字字动画。
3. 备份原插件文件夹，用解压后的程序文件覆盖同名文件。
4. 保留已有 config.json 和 .state 文件夹，不要先删除整个旧插件目录；也不要清理字字动画的用户配置目录。
5. 重启字字动画。1.0.x 旧版需要这样手动升级一次，之后即可在插件内更新。

四、常见问题
· 找不到插件：检查最终路径是否为 video_plugins\video_plugin_site_api\main.py，确认解压正确并重启。
· 没看到新版：点击“检查更新”；只有网站已发布的版本才能被检测到。
· 新模型没有出现：点击“刷新模型”，确认自己的 API Key 有该模型权限；模型列表和规格按网站同步。
· 特殊参数因模型而异：仅显示网站已声明支持的选项，不同模型的开关数量可以不同。
· 提示先重启：仅关闭设置面板不够，需要退出并重新打开字字动画。
· 已完成任务没有出现在分镜：打开“任务记录与取回”，查询并取回原任务，再在作品中使用“找回未记录的生成结果”；不要为了取回结果重复点击生成。

请只分享干净安装包，不要向别人发送自己的 API Key、config.json、.state 或整个字字动画安装目录。
