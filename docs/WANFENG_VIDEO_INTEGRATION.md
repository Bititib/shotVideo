# 晚风视频渠道

在后台打开 **渠道管理 → 新增渠道**，选择 **晚风 API（视频）**，填入晚风 Key 并保存。默认请求地址是 `https://api.pro666.top`。

打开该渠道的 **模型与参数 → 添加新模型 → 读取晚风公开型号**，选择上游 ID，填写本站 API 模型 ID 和显示名称。后台按型号填入时长、清晰度及素材上限。可以在 **请求体样例** 核对映射。新增模型默认停用，在关联模型中设置本站售价和访问权限后启用。

型号来自晚风的 [公开视频能力表](https://pro666.top/docs/#matrix)。公开目录用于选择型号，账户权限以该 Key 的实际授权为准。渠道的连接测试是只读检查。

网站、开放 API 和批量任务使用同一个视频规格映射。系统发送统一视频 JSON，保存创建回执的 `id` 或 `task_id`，后续用保存的编号查询和下载。查询或下载出现暂时错误时继续处理原任务。明确拒绝和任务失败进入原订单退款，提交结果未知时转待核实。

本次实现范围为统一视频接口。Doubao 专属格式及图片生成接口在 [晚风 API 文档](https://pro666.top/docs/) 中另有说明。
