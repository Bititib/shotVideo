# BB、HSS 独立切换生成来源

2026-11-02。保留公开 ID `bb-2.5-301010`、`hss-2.5-301010`。后台「模型管理 → 编辑对应模型 → 新任务生成来源」，选择来源与已配置的渠道，再点「切换来源」。两个入口分别保存选择，不会一起切换。来源选择立即保存，不依赖模型编辑框底部的保存按钮。

支持现有适配器已接入的三个来源，不新增未知型号或自动备用：

| 来源 | 渠道类型 | 真实上游型号 | 规格 |
| --- | --- | --- | --- |
| KK | zongheng-v6k | kkseadanco2.5 | 720p，5–30 秒，16:9/9:16/1:1 |
| HUSS A | huss | bb-2.5-301010-渠道A | 720p，5–30 秒，沿用 A 已验证比例；图片/视频/音频合计最多 30 个 |
| HUSS B | huss | hss-2.5-301010-渠道B | 720p，4–30 秒，沿用 B 已验证的六种比例 |

均保留各项最多 30 图、10 视频、10 音频、一次一条，不支持独立首尾帧。切换更新规格限制，网站、API、画布和批次的实际生成继续走规格服务 → 现有渠道适配器。A 的素材合计限制现在也在创建订单、预扣前校验，不静默删素材。两入口标准价沿用之前的 ¥6.5/条；本次切换不修改标准价格、个人价格或历史快照，也不打开管理员关闭的模型、规格或线路开关。

保存前仅调用所选渠道的鉴权 `GET /v1/models`，要求明确列出对应真实 ID。渠道关闭、未配置 Key、未授权该型号、HTTP 错误、非 JSON、查询期间配置变化，都保留原来源。不能通过切换使上游已下架的型号恢复可用；旧 A/B 是否还能调用，以该 Key 当前的模型列表为准。此只读核对不会创建付费任务。

新来源保存在 `bb_hss_video_sources_v1`；切换事务同时更新一个公共入口的规格与支持列表/映射。原渠道的地址、密钥、其他产品保留。启动、旧 A 迁移和普通 HUSS/V6K 同步均不会改回默认 KK 或添加其他来源。通用规格保存和队列发送前也核对来源，防止手填线路绕过选择。相同选择重复保存不扩大管理员后来收紧的限制。并发切换只允许先完成的一次保存，后完成的返回配置冲突。

切换不会写订单、余额、预扣、退款或原任务凭据。已接单的任务从原渠道、Key、ID、回执和价格快照恢复；相同 API 幂等请求重试仍返回原任务，不因切换生成新任务。切换期间尚未发送而持有旧线路的请求，在发送前重新校验；原线路已撤销时停止该次发送并沿用现有一次性退款机制，不静默改参或重建任务。新建请求才按新来源执行，不按失败自动跨源补单。

协议依据：[HUSS 官方接入指南](https://www.huss.top/api-docs/ai-integration.md) 当前说明 `/v1/models` 为账号权限依据，统一视频提交、原任务查询和原幂等键恢复；[V6K 文档](https://www.v6k.top/docs?guide=unified&category=video) 及仓库现有 KK 接入说明。未改变两个上游各自的状态、错误码和退款判定规则。
