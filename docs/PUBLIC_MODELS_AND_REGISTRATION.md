# 公开模型目录与用户自主注册

更新日期：2026-10-31。

## 用户看到的变化

- `/app/docs?tab=models` 默认展示公开模型目录，访客和没有 API Key 的已登录用户均可查看型号、标准售价、规格和调用示例。
- 已登录用户仍可选择自己的 API Key，查看该 Key 的授权范围及个人专属价格，也可切回公开目录。公开目录不会自动选择用户的第一个 Key，Key 列表加载失败也不阻断公开浏览。
- 登录弹窗增加“立即注册”，填写邮箱、用户名、密码和确认密码后自动登录。长表单限制在当前视口高度内滚动。

## 服务器调用链

公开目录：`DeveloperPage` → `ApiModelsPage` → `developerApi.getPublicModels` → 无需登录的 `GET /api/developer/models/public` → `getPublicDeveloperModels`。复用现有经过管理员确认、已启用且实际可路由的目录筛选与公开元数据投影，仅返回站点标准价格、公开能力和汇总状态；响应 `token=null`，不返回渠道、上游 Key、Token 信息或用户个人价格。响应不缓存。

个人目录仍通过登录保护的 `GET /api/developer/models?tokenId=...` 获取，保留 Token 归属检查、授权过滤和个人价格。页面在切换目录时取消旧请求，不显示迟到的其他 Key 或个人目录结果。`GET /v1/models` 和实际付费 API 调用继续要求用户自己的 API Key。

注册：`LoginModal` → 原 `authStore.register` / `authApi.register` → `POST /api/auth/register` → `AuthService.register` → 原 JWT 与 `/api/auth/me` 会话流程。

- 只接受邮箱、用户名和密码；服务器固定创建普通 `user`、免费等级、零余额、无组织的有效账号，不接受请求中的角色、余额、等级或组织赋值，不自动创建 API Key。
- 邮箱去空白并转小写，用户名去空白，服务端验证类型、邮箱格式、用户名长度及密码长度；密码以异步 bcrypt 12 轮哈希保存。检查大小写重复邮箱，并对并发唯一约束冲突返回明确的重复注册提示。
- 登录优先匹配既有完整邮箱，随后兼容标准化邮箱，保留旧账号的精确匹配行为。
- 注册接口单独按 IP 限制每小时 10 次尝试，并继续经过应用原有认证接口限流。管理员创建账号、充值和所有付费调用权限不变；本次不开放模拟自助充值，不新增支付、邮箱验证或验证码服务。
